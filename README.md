# PrimeCare Clinic — React + Vite

This is a React project with a root `index.html` file.

## Run it

1. Open this folder in VS Code.
2. Open the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Main files

- `index.html` — HTML entry point
- `src/main.jsx` — connects React to `#root`
- `src/App.jsx` — website sections and React interactions
- `src/style.css` — all website styling
